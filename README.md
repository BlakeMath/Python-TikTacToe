# Python Tic Tac Toe

A simple two-player Tic Tac Toe game that runs in the terminal using Python.

## Requirements

- Python 3

## How to Run

1. Open a terminal in the project directory.
2. Run:

```bash
python "Tik Tac Toe.py"
```

## How to Play

- Player 1 chooses whether to use `X` or `O`.
- The game randomly selects which player goes first.
- Players take turns choosing a board position from `1` to `9`.
- The first player to complete a row, column, or diagonal wins.
- If all spaces are filled without a winner, the game ends in a draw.

## Board Layout

The board positions are numbered like this:

```text
7 | 8 | 9
---------
4 | 5 | 6
---------
1 | 2 | 3
```

## Replay

After each game, players can choose to play again by entering `Y` or quit by entering `N`.
